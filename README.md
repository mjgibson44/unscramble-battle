# Unscramble Battle

A word unscramble game in a single file (`index.html`). No build step: open it in a browser.

- **Battle:** two players share one phone or tablet, sitting on opposite sides. Both get the same scrambled 5–8 letter word. Tap letters to spell it. The first to solve it gets the point, and the first to reach the target (1–10, set on the menu) wins.
- **Solo Sprint:** ten words. Each word is worth 100 points per letter and drains the longer you take. Your best score is saved on the device.
